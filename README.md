# Meta Front-End Capstone Project

This project was created as part of the Meta Front-End certification. It is a simple website for a fictional restaurant called Little Lemon.

## Tech stack

- **Framework**: React (with React DOM)
- **Build tool**: Vite
- **Language**: TypeScript
- **Routing**: React Router
- **Forms & validation**: Formik and Yup
- **Testing**: Vitest and React Testing Library
- **Linting/formatting**: ESLint and Prettier

## Run it locally

This project is not currently deployed. To run it locally, follow the steps below:

```bash
# After cloning the repo, go to the project folder and install the dependencies
npm install

# Then run the development server
npm run dev
```

## Run unit tests

To run the unit tests locally, use:

```bash
npm run test
```
